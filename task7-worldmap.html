Using HTML Image Maps - <img>, <map>, <area>

How Image Map Works (As per assignment):

  • rect - for a rectangular region - Used for USA - coords="x1,y1,x2,y2"
  • circle - for a circular region - Used for India & Australia - coords="x,y,radius"
  • poly - for an irregular/polygon-shaped region - Used for Brazil & Africa - coords="x1,y1,x2,y2,x3,y3..."
  • default - for the remaining area (Ocean) - Opens World Map page

All links have target="_blank" so they open in a new tab, and alt attribute for description.
